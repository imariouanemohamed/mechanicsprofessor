The MP learning loop

From intuition to engineering proof

Every new laboratory will use the same five-step method so that students learn the reasoning, not only the final number.

  1. 01
    ?

    Predict

    Choose what you think will happen before changing the model.

  2. 02
    ＋

    Build

    Configure geometry, material, fluid and boundary conditions.

  3. 03
    ▶

    Simulate

    Run the model and watch the physical response evolve.

  4. 04
    =

    Verify

    Compare the simulation with the governing equation.

  5. 05
    ★

    Challenge

    Solve a design task under realistic engineering limits.
