Cette archive contient la version complète du site centrée sur les futurs
cours Udemy de mécanique et sur la newsletter MechanicsProfessor.

- MP Labs et tous les liens vers les laboratoires ont été supprimés ;

- les références aux futurs outils et laboratoires ont été retirées.

REMPLACEMENT DANS VS CODE
-------------------------
1. Décompressez l'archive téléchargée.
2. Ouvrez votre dossier local :
   C:\Users\Dell Pro\mechanicsprofessor
3. Supprimez entièrement le dossier « labs » s'il existe encore.
4. Copiez TOUT le contenu du dossier décompressé dans le dossier du site.
5. Acceptez le remplacement des fichiers existants.
6. Dans le terminal VS Code, exécutez :

   git add -A
   git commit -m "Focus MechanicsProfessor on Udemy courses"
   git push

Cloudflare mettra automatiquement le site en ligne après le push.

APRÈS LA PUBLICATION
--------------------
- actualisez le site avec Ctrl + F5 ;
- vérifiez la page d'accueil sur ordinateur et téléphone ;
- testez l'inscription à la newsletter avec une adresse email réelle ;
- vérifiez que l'ancien chemin /labs/ n'est plus publié.
