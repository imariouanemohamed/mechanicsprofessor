HOW TO USE IN VS CODE
1. Make a backup of your current project.
2. Copy index.html and style.css into your project folder.
3. Copy the images folder into your project folder.
4. Open index.html with Live Server.
5. Review the page.
6. Update email, LinkedIn, Udemy and publication links when ready.

HOW TO PUBLISH
1. In VS Code, open Source Control.
2. Stage all changes.
3. Commit message: "Launch complete MechanicsProfessor homepage"
4. Click Sync Changes / Push.
5. Wait 1-2 minutes for Cloudflare deployment.
6. Open https://mechanicsprofessor.com and refresh with Ctrl+F5.
